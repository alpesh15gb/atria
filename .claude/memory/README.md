# Long-Term Memory

Store detailed project knowledge here that should survive compaction and new sessions.

Good examples:

- architecture details
- debugging discoveries
- API notes
- database schema knowledge
- important research
- migration notes
- session summaries

Suggested structure:

```text
.claude/memory/
├── architecture.md
├── backend.md
├── frontend.md
├── database.md
├── bugs.md
├── research.md
└── sessions/
    └── YYYY-MM-DD.md
```

Do not automatically load this whole directory into context.

Search it and read only the relevant files or sections.
